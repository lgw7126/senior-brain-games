# 🧓 시니어 두뇌 게임 모음 (Senior Brain Games)

한국 시니어를 위해 만든 **눈이 편안하고, 성취감 있고, 중독성 있는** 모바일 웹 게임 모음입니다.
설치 없이 브라우저에서 바로 실행되며, 인터넷 연결 없이도 작동합니다.

## 👵 공통 설계 원칙

- **눈 편안함**: 한지색 저채도 배경, 큰 글씨(글자 크기 토글), 높은 명도 대비
- **쉬운 조작**: 큰 버튼(최소 60px), 탭 한 번으로 모든 조작, 시간 압박 최소화
- **성취감 곡선**: 아주 쉬운 초급에서 시작해 단계적으로 고난도로
- **도파민 설계**: 연속 콤보, 피버 모드, 점수 레이스, 보상 뽑기, 폭죽·효과음
- **무설치·무료**: 외부 라이브러리 0개, HTML 파일 하나로 완결

## 🚀 실행 방법

1. 원하는 게임 폴더의 `index.html`을 휴대폰/컴퓨터 브라우저로 열기
2. 또는 GitHub Pages를 켜면 링크 접속만으로 플레이 가능
   - 저장소 **Settings → Pages → Branch: main → Save**
   - 주소: `https://<아이디>.github.io/<저장소이름>/proverb-stepping-stones/`
